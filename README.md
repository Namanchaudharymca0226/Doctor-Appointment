# Doctor Appointment System
A web-based Smart Queue Management System designed to streamline doctor appointment bookings and manage patient visits efficiently.

## Features
* **Patient Portal**: Book and view appointment details.
* **Doctor Dashboard**: Manage queues and patient lists in real time.
* **Interactive UI**: Clean, responsive layout for easy navigation.

## Tech Stack
* **Frontend**: HTML5, CSS3, JavaScript
* **Dependencies**: Node.js (`package.json`)

## Repository Structure
* `index.html` - Main landing page / booking portal
* `doctor.html` - Doctor dashboard page
* `script.js` - Client-side application logic
* `doctor.js` - Doctor panel functionality
* `style.css` - Custom styling for the application
* `package.json` & `package-lock.json` - Project metadata and dependencies
